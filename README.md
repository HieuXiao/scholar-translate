# Scholar Translate

SciTranslate is an AI-powered translation system designed for scientific papers and academic documents.

Unlike conventional translators, SciTranslate preserves the original document structure, including:

- Titles and headings
- Tables and figures
- Citations and references
- Mathematical equations
- Academic formatting

The system extracts document structure, translates textual content using Large Language Models (LLMs), and reconstructs the final document while maintaining layout consistency.
